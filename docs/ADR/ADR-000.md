# ADR-000

## Title

Unified Crystal Database and Metadata Strategy

Status: Accepted

Date: 2026-08-06

---

# Context

本プロジェクトは、

- Crystal Generation
- Information Acquisition
- Information Extraction
- Crystal Intelligence

の4テーマから構成される。

Theme 1〜3においては、

これまで約20年にわたり蓄積された

- 地上結晶
- 宇宙結晶
- 高圧凍結結晶
- 超高分解能回折データ
- 精密化データ

が存在する。

特に、

Bovine H-proteinを対象として、

- 0.88 Å構造解析
- 0.86 Å高圧凍結構造解析
- 0.79 Å宇宙結晶データ収集
- 0.73 Å宇宙結晶フルデータ収集

まで到達している。

しかし、

これらのデータは

- 実験ノート
- 回折データ
- 精密化結果
- 結晶写真
- Beamtime記録
- 宇宙実験記録

として分散して保存されており、

共通メタデータ基準による統合管理は行われていない。

現在のProject Charterでは、

Crystal Intelligence

を最終到達目標の一つとして定義している。

しかし、

- ODC
- Machine Learning
- Graph Neural Network
- Reinforcement Learning

はいずれも、

整理されたデータ基盤を前提とする。

また、

ADR-001で採用したChunk解析、

ADR-002で採用したCryoprotectant評価についても、

過去データとの比較が不可欠となる。

したがって、

本プロジェクトでは

データベース整備を研究インフラとして正式採用する必要がある。

---

# Decision

本プロジェクトでは、

過去および将来取得される

すべての結晶化・回折・構造解析データを、

共通メタデータ基準で記録する。

また、

地上結晶と宇宙結晶を統一的に比較可能な

Crystal Database

を構築する。

本決定を、

Project Charterにおける

Theme 4

Crystal Intelligence

実現のための最優先基盤整備と位置付ける。

---

# Objective

本ADRの目的は、

過去約20年間に蓄積された

H-protein研究データを統合し、

比較可能な研究資産へ変換することである。

具体的には、

- Ground vs Space比較
- Cryoprotectant比較
- Chunk解析
- ODC開発
- Crystal Quality Prediction

を可能にする基盤を構築する。

# Motivation

本プロジェクトの目的は、

単なる高分解能構造解析ではない。

最終的には、

- 結晶品質を説明する
- 結晶品質を予測する
- 結晶品質を設計する
- 情報量を最大化する

ことを目指している。

しかし、

これらは全て

比較可能なデータ基盤

が存在しなければ実現できない。

Database整備は単なる記録作業ではなく、

Crystal Intelligence実現のための研究活動そのものである。

---

# Alternatives Considered

## Alternative 1

必要になった時に個別にデータを収集する。

### Reason for Rejection

過去データの所在や条件が失われる可能性が高い。

再解析が著しく困難となる。

---

## Alternative 2

論文化済みデータのみ整理する。

### Reason for Rejection

Cryoprotectant条件や失敗実験など、

重要な情報の多くが失われる。

---

## Alternative 3

ODC開発開始後に整備する。

### Reason for Rejection

ODC開発そのものがデータベースを前提とする。
