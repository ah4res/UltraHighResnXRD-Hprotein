# Roadmap

本プロジェクトは4つの研究テーマから構成される。

---

# Theme 1

## Space Crystallization

宇宙結晶化条件の最適化

### Objective

微小重力環境下で再現性高く
高品質単結晶を取得する。

### Topics

- 試料調製法
- 精製法
- カウンターディフュージョン法
- 結晶サイズ最適化
- 結晶クラスター化抑制
- 宇宙結晶再現性向上

### Milestone

- 高品質単結晶取得
- 宇宙結晶化条件体系化

---

# Theme 2

## Diffraction Data Collection

宇宙結晶の回折実験最適化

### Objective

超高分解能回折データ取得条件を確立する。

### Topics

- Cryo条件
- Cryo-protectant最適化
- Dose最適化
- Beam size選択
- 高エネルギーモード活用
- BL41XU
- PF NW12A

### Milestone

- 0.7 Å台の安定収集
- 0.6 Å台への到達

---

# Theme 3

## Ultra-High Resolution Structure Analysis

超高分解能構造解析法の確立

### Objective

超高分解能データから
最大限の構造情報を抽出する。

### Topics

- Data Reduction
- Refinement
- Hydrogen Visualization
- Charge Density Refinement
- Ground vs Space比較

### Milestone

- 水素原子可視化
- Charge Density解析実施

---

# Theme 4

## Crystal Intelligence

過去データの体系化とAI活用

### Objective

過去の結晶化・回折・構造解析データを
知識化する。

### Topics

- Historical Data Integration
- Crystal Database構築
- Experimental Metadata整理
- Ground vs Space比較
- Machine Learning
- Crystal Quality Prediction
- Experimental Design Recommendation

### Milestone

- Crystal Database完成
- 宇宙結晶品質予測モデル構築
- 実験設計支援システム構築

---

# Long-Term Goal

地上結晶と宇宙結晶を統合的に理解し、

- 宇宙結晶品質を説明する
- 宇宙結晶品質を予測する
- 宇宙結晶品質を設計する

ことを目指す。
