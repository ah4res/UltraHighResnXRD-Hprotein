# Consistency Check

Current_State更新時には必ず確認する。

- 未反映のAccepted ADRはないか
- 未反映のEvidenceはないか
- 未反映のResultはないか
- Charterと矛盾していないか
- Roadmapと矛盾していないか
- Superseded ADRが残っていないか
- Rejected ADRが残っていないか
- Current_StateとADR間に矛盾がないか
- Current_StateとEvidence間に矛盾がないか
- Current_StateとResult間に矛盾がないか

---

# Update Policy

Superseded ADRは反映しない。

Rejected ADRは反映しない。

Resultによって否定された仮説は削除する。

Evidenceによって否定された内容は削除する。

Current_Stateには

現在有効な内容のみ記載する。
