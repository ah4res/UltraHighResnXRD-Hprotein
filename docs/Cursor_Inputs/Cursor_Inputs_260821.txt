External network connectivity will be unavailable from:

## Requirement 1: Offline Execution

The pipeline must not require:

- Internet access
- Package downloads
- Remote API calls
- Cloud services
- Git pull or repository updates
- External databases

after job launch.

All required files, scripts, binaries and configuration files must be validated before launch.

The complete workflow must survive the network outage period without human intervention.

---

## Requirement 2: Memory Safety First

The highest priority is avoiding system shutdown caused by memory exhaustion.

Under no circumstances should total RAM usage exceed:

**100 GB**

Prefer:

- lower parallelism
- slower throughput
- sequential execution
- batched processing

rather than aggressive parallel execution.

Analysis efficiency is secondary.

Completion by Monday afternoon is sufficient.

---

## Requirement 3: Staged Processing

Design the workflow as independent restartable stages.

Example:

### Stage 1

Full dataset processing

### Stage 2

Chunk generation

### Stage 3

Chunk processing

### Stage 5

Chunk quality mapping

### Stage 6

After completion of every dataset or chunk:

- update progress log
